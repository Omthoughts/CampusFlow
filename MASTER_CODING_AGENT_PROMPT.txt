SOURCE-OF-TRUTH RULE:
The official college documents are authoritative for academic facts. AI/OCR is assistive. Never invent dates, requirements, penalties, rooms, eligibility or deadlines. Human review is required before extracted academic information is published.

FINAL TECHNOLOGY DECISIONS:
Frontend React + TypeScript + Vite + Tailwind + React Router + TanStack Query + React Hook Form + Zod.
Backend Node.js + TypeScript + Express.
Database PostgreSQL on Neon + Prisma.
Auth secure httpOnly session cookies + Argon2id.
File storage Cloudinary.
AI Google Gemini API behind an internal adapter.
OCR Tesseract.js.
Scraping Cheerio; Playwright only if required.
Frontend deployment Vercel.
Backend deployment Render.
Testing Vitest + Supertest + Playwright.
Sentry optional.
No Redis in MVP.

MVP:
College-email login; student dashboard; notices; deadlines; events; event registration; calendar; in-app notifications; profile; admin dashboard; notice/event publishing; audience targeting; registration management; audit logs; PDF/image upload; PDF extraction/OCR; human review; AI summary; controlled official-source ingestion.

DO NOT BUILD IN MVP:

College -> Department (MCA, MBA) -> Year (FY, SY) -> Division (A, B) -> Batch (F1, F2, F3).

FINAL AUTH:
College email + password. NOT PRN. Normalize email with email.replace(/\s/g,'').toLowerCase(). Domain @moderncoe.edu.in.
